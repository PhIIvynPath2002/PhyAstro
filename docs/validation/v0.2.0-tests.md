## Scientific And Geometry Coverage

- Common time, frame, units and position kind for all body vectors.
- Antisymmetric relative vectors and symmetric distances for all body pairs.
- Triangle closure and physical range sanity at all four required snapshots.
- Independent angular-diameter formula, dimensionless directions and invalid-input handling.
- Barycentric-to-heliocentric/geocentric translation consistency inside the library;
  this is not represented as independent JPL reference validation.
- UTC/Beijing/New York conversion; New York spring and autumn DST boundaries.
- Display-zone and render-scale changes preserve scientific snapshots.
- Swept camera collision, overlap recovery and extreme zoom outside every sphere.
- Camera-relative km conversion and old mean-of-date reference precession.
- Actual-camera frustum and basic full/partial sphere occlusion.

## Browser And Offline Coverage

- Three persistent meshes, six Observer/Target combinations, target aiming and recentering.
- All body states update together on snapshot change; valid centre/target selections persist.
- Physical mode uses true radii; enhancement changes render radii only.
- Real greyscale body pixels for Earth, Moon and Sun; desktop/mobile screenshots.
- Debug panel controls, mobile layout, wheel rotation, touch drag and pinch zoom.
- Direct zoom-button actions also refresh actual camera-position readouts while
  leaving the scientific snapshot unchanged.
- Compatibility instrument, line double-clicks, bilingual terms and time handoff.
- Arrow/hand cursor restoration after release and interrupted dragging.
- Two complete compatibility-view turns restore rendered pixels after settling.
- Self-contained classic-script document with all libraries/assets inline and
  bundled third-party license notices.

## Environment And Limits

Node.js 24.19.0, npm 11.9.0, Chromium on Linux with software WebGL rendering.
The final system tests used the local development server on port 5174; an older
server on port 5173 was left untouched. The temporary 5174 server was stopped
after validation because delivery is the offline file.

The offline document was loaded with `page.setContent` in a browser context
with networking disabled. This cloud browser forbids direct `file://`
navigation; a native local-file launch is not claimed as tested. Actual macOS
Chrome and Windows Edge machines were not available. Recent Chromium-based
Chrome/Edge with WebGL 2 and graphics acceleration are the intended browsers.

The production build reports the existing large Three.js chunk warning. This
is not a failed build and requires no runtime CDN or external chunk in the
single-file export.

`npm run report:science` preserves the exact failed Horizons query and leaves
all reference values and errors null. Cross-library calculated differences
are documented separately. No external accuracy certification has been made.
